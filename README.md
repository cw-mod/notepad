# CatWar: Notepad 📓

Сворачиваемый мини-блокнот с вкладками для catwar.su / catwar.net.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [страницу установки](https://cw-mod.github.io/notepad/) и нажмите «Скачать юзерскрипт».
3. Откройте catwar.su или catwar.net — на экране появится кнопка 📓, за неё тянется панель блокнота.

## Возможности

- Вкладки-заметки: добавление (＋), переименование (клик по названию), удаление (✕), кнопка ➤ в шапке — быстрый список всех вкладок.
- BB-код-редактор: жирный, курсив, подчёркнутый, зачёркнутый, ссылки, картинки, цвет и фон текста, размер, заголовки, цитаты, спойлеры, списки, выравнивание.
- Экспорт / импорт всех заметок в JSON (иконки в подвале панели).
- Настройка темы: 10 цветов панели, живое применение, сброс к стандарту.
- Сворачивание (—), фиксация позиции (🔒), перетаскивание панели и кнопки.
- Искряшки ✨ (отключаются в настройках).

## Хранение данных

Заметки хранятся в Tampermonkey (`GM_setValue`), с откатом на `localStorage` (префикс `cwNotepad_`), если GM-хранилище недоступно. Данные не покидают браузер.

## Обновления

Скрипт обновляется автоматически через GitHub Pages:
- `@updateURL`: <https://cw-mod.github.io/notepad/catwar-notepad.meta.js>
- `@downloadURL`: <https://cw-mod.github.io/notepad/catwar-notepad.user.js>

## Разработка

Файлы:

- `catwar-notepad.user.js` — сам скрипт;
- `catwar-notepad.meta.js` — заголовок для проверки обновлений;
- `index.html` — страница установки.

Синтаксис проверяется: `node --check catwar-notepad.user.js`.
